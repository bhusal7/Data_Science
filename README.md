# Data Science

A collection of data science, machine learning, and computer vision projects, notebooks, and exercises — covering everything from core Python fundamentals to deep learning with PyTorch.

## 📁 Repository Structure

| Folder | Description |
|---|---|
| [`Data Visualization`](./Data%20Visualization) | Notebooks and scripts for visualizing datasets using libraries such as Matplotlib and Seaborn. |
| [`Heart_Disease_Predictor`](./Heart_Disease_Predictor) | An end-to-end machine learning project for predicting heart disease risk from patient data. |
| [`NLP`](./NLP) | Natural Language Processing experiments — text preprocessing, tokenization, and language models. |
| [`NumPy`](./NumPy) | Exercises and examples demonstrating array operations and numerical computing with NumPy. |
| [`OpenCV/FaceDetection`](./OpenCV/FaceDetection) | Computer vision projects using OpenCV, including face detection and related image-processing techniques. |
| [`Pandas`](./Pandas) | Data manipulation and analysis examples using the Pandas library. |
| [`PyTorch`](./PyTorch) | Deep learning experiments and models built with PyTorch. |
| [`Python`](./Python) | General Python programming exercises and fundamentals. |
| [`Sci Kit Learning`](./Sci%20Kit%20Learning) | Machine learning models and workflows built with Scikit-learn. |
| [`Statistics`](./Statistics) | Statistical concepts, methods, and their practical implementation. |
| [`anaconda_projects/db`](./anaconda_projects/db) | Supporting project database files generated by the Anaconda environment. |

## 🛠️ Technologies Used

- **Python**
- **NumPy** & **Pandas**
- **Matplotlib** / **Seaborn**
- **Scikit-learn**
- **PyTorch**
- **OpenCV**

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/bhusal7/Data_Science.git
   cd Data_Science
   ```
2. (Recommended) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate   # On Windows: venv\Scripts\activate
   ```
3. Install common dependencies as needed for each project (e.g.):
   ```bash
   pip install numpy pandas matplotlib scikit-learn torch opencv-python nltk
   ```
4. Navigate into any folder above and open the notebooks/scripts inside.
